# 使用指南

需要自动布局、外壳和固定件时，使用新的
[外壳与自然语言入口](外壳与自然语言.md)。
下文前两节主要说明保留兼容的低层底板接口。

## 1. 安装与示例

需要 Python 3.11+。CadQuery 2.8 的实际 Python 要求高于某些上游 README 中的说明。
安装命令见根目录 README。若系统只有旧 Python，可用已有的 uv：

```bash
uv python install 3.11
uv venv --seed --python 3.11 .venv
uv pip install --python .venv/bin/python -e '.[dev,mcp]'
.venv/bin/fastbuild demo --output build/demo
```

完整示例输出：

```text
build/demo/
├── inputs/
│   ├── controller.step
│   ├── sensor.step
│   └── design.yaml
└── result/
    ├── assembly.step
    ├── mounting_plate.step
    ├── design.yaml
    └── validation.json
```

所有模型均为合成测试件；安装柱只有贯穿间隙孔，不包含螺纹、嵌件和锁紧结构。
STEP 文件可以直接在 FreeCAD 打开，分辨安装底板和两个器件。

```bash
.venv/bin/fastbuild build examples/design.yaml --output build/example
```

此命令在 demo 已执行后可直接运行。对真实模型，先替换 YAML 的 STEP 路径和孔位。
每个 STEP 当前必须恰好包含一个有效实体；装配输入需先拆分到器件级。
配置也接受 JSON，使用同一份包内 JSON Schema；未知字段、重复名称、重复 YAML
键、NaN/Infinity 均会拒绝，避免拼写错误被静默忽略。

## 2. 坐标与接口

- 底板以 XY 中心为原点，底面 Z=0。
- `devices[].position` 为器件局部原点的 XY 位置，单位 mm。
- `rotation_deg` 为绕局部原点的 Z 轴旋转，随后平移。
- 器件局部安装底面必须位于 Z=0；安装孔沿 +Z 贯穿。
- `mounts` 为器件局部孔中心；`mount_hole_diameter` 声明需要验证的贯穿孔径。
- 器件实际底面必须覆盖安装柱的接触环，防止把外部空白误认为安装孔。
- 器件世界 Z 为 `plate.thickness + standoff`。
- `keepouts` 是器件局部坐标下的轴对齐盒，随器件旋转和平移。
  检查其他器件及安装底板对它的侵入；本器件自身不参加此项。
- `clearance` 控制器件间、安装柱之间、安装柱与非所属器件的最小距离。
  所属安装柱与器件的零距离接触是预期行为，但实体穿透仍会失败。
- `edge_margin` 为器件包围盒和安装柱外缘到矩形底板边界的最小距离。
- `mounting.min_wall` 控制安装柱标准间隙孔以外的最小径向壁厚；
  这只是声明的模板规则，不是工艺认证。

当前不支持任意倾角、侧面孔、盲孔、复杂接触和运动装配。
不要求必须有禁入区，但未声明的线缆、接口和散热空间不会自动得到保护。
通过几何检查仅意味着本阶段声明的规则通过，不意味着产品可投产。

## 3. 复用上游 MCP

不在本仓库重写 MCP Server。安装可选依赖：

```bash
.venv/bin/python -m pip install -e '.[mcp]'
```

将以下片段加入所用 MCP 客户端的配置，并替换为**绝对路径**：

```json
{
  "mcpServers": {
    "cadquery": {
      "command": "/absolute/path/to/fastbuild/.venv/bin/cadquery-mcp"
    }
  }
}
```

这是通用配置示意，不会自动修改任何客户端设置。
先将 YAML 作为 Agent 可以编辑的参数文件，并要求 Agent 调用 `fastbuild build`，
仅在命令成功且检查报告通过时接受结果。让 Agent 先选模板和修改参数，
不要绕开检查直接输出“合格”。

上游 MCP 的 render / inspect / export 接受的 CadQuery 代码可以复用本项目：

```python
from pathlib import Path
from fastbuild.config import load_design
from fastbuild.pipeline import create_model

result = create_model(load_design(Path("/absolute/path/to/design.yaml"))).assembly
```

这会执行几何检查，但不执行本项目的 STEP 重导入和完整报告持久化。
正式交付仍以 `fastbuild build` 的产物为准。
PNG 需要有效的 VTK/OpenGL 后端；无显示环境可显式使用 SVG。
不要把渲染成功当几何/强度检查通过。

MCP 接受可执行 Python，当前接入不是安全沙箱。只对可信本地操作使用；
生产环境需要另加容器隔离、路径和网络权限限制、超时及资源上限。
当前没有自建 LLM 调度器，也未配置或调用任何云端模型。

## 4. FreeCAD 人工复核与宏

安装 FreeCAD 后可以手工打开 `assembly.step` 测量和检查。
另提供一个在 FreeCAD 内执行的宏，重导入并核对有效性、实体数和总体积：

```bash
FASTBUILD_RESULT_DIR="$PWD/build/demo/result" \
  FreeCAD "$PWD/tools/check_freecad.FCMacro"
```

Linux 的可执行文件也可能名为 `freecad`。某些版本需要在 GUI 中手动执行宏。
宏成功后产生 `inspection.FCStd` 和 `freecad-validation.json`。
如果缺少环境变量或检查失败，会抛出错误而非写成功报告。

FCStd 仅保存检查场景，不包含恢复的 CadQuery 参数化历史。
此宏不执行 FEM，也不代表独立内核交叉验证。
运行环境没有 FreeCAD 时，不会自动伪造其检查结果。

## 5. 验证命令

```bash
.venv/bin/python -m pytest -q
.venv/bin/ruff check .
.venv/bin/ruff format --check .
```

外壳依赖安装后，测试前需按上游要求执行一次
`.venv/bin/python tools/prepare_enclosure.py`，准备当前虚拟环境的紧固件 CSV。

安装 `[mcp]` 后，测试还会实际启动上游 MCP Server，检查 inspect/export 及错误返回；
未安装该可选依赖时，此项明确标记 skipped。
几何测试包含真实 STEP 重导入及位置保持、参数快照、旋转孔位、碰撞、间隙、
支撑落脚面、禁入区、无效配置和 CLI 失败行为。

依赖使用上游固定提交；CadQuery 版本固定在 `pyproject.toml`。
后续升级应先运行上述测试，再评估 cq_enclosure_builder 的旧 API 和紧固件数据兼容性。
